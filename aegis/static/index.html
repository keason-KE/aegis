What this evaluation establishes

Deterministic enforcement

Exercises legitimate access, privilege escalation, injected tool calls, credential expiry, revocation, approval replay, and audit failure.

Model behavior is separate

The injection test deliberately attempts the forbidden call. Use Live Ollama in the playground to observe an actual model's response.

Deployment isolation

Local processes share your OS permissions. The Docker lab provides a separate agent container and a dedicated bypass probe. See the project guide for the measured result.
